# Stop inventory and placement controls

Task 6 adds a stop-wide file inventory above the current beat. Anchor numbers and colors stay attached to their source across navigation, filtering, grouping, and placement. A beat highlights its active subset without removing other anchors.

A single anchor is named in the header; 2–4 anchors use compact rows. Larger stops support In view and all seven role groups (change, evidence, caller, callee, config, schema, context), text filtering and numeric order. At 12+ anchors, inactive role sections start collapsed. The scrolling list mounts only the visible rows plus a small overscan, including at the configured 99-anchor ceiling. Every row names the file, change status and directory/range/label. Role section headings pair a neutral icon with their name and count. In View rows replace position text with a role icon; compact lists and Order mode also show role icons because there is no role heading. Rows under role headings omit the redundant role. Icons have full-name tooltips and accessible labels; numbered colors remain dedicated to file identity. Placement choices still name their destination.

Open an unopened anchor to choose a placement. The picker shows numbered layout diagrams for eligible Below, Beside and Replace choices plus Peek. At capacity, only eligible replacements and Peek remain. Pins exclude protected destinations. Remember for this role stores the chosen destination within the loaded tour; subsequent opening uses it when still valid. Move offers explicit placement for an existing tab without duplicating it. Reset clears tour pins and customization while retaining role preferences and protected reviewer tabs.

Find file (Alt+0) searches numbers, filenames, paths, roles and labels. Enter opens placement choices, Alt+Enter peeks, and Shift+Enter replaces the group focused before the picker opened. Alt+1–9 selects anchors 1–9; Alt+Shift+0–9 selects 10–19. List arrow keys, Home and End navigate rows; Escape dismisses placement. All anchors, including numbers above 19, remain reachable through search or the list.

The webview renders source metadata as text, retains the existing escaped Markdown renderer, and submits revision-bound intents. The extension revalidates placements against current tabs and pins. Native Peek uses the awaited `goToLocations` command; explicit moves track destination group identity because native empty-group cleanup can renumber columns. Preview diagrams also omit a source group that the native setting will close.
